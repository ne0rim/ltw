# Human base mesh source

`extracted/human-base-meshes-bundle-v1.4.1/human_base_meshes_bundle.blend` is
Blender's Human Base Meshes v1.4.1 bundle by Blender Studio and community
contributors. Blender lists the bundle as CC0 and requires Blender 4.2 LTS or
newer. The soldier build script uses its `GEO-body_male_realistic` mesh and eye
objects as the human base.

Official source: https://www.blender.org/download/demo-files/
